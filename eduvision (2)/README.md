# EduVision: AI-Powered Doodle Animation Engine 🚀🎨

EduVision is a full-stack, high-fidelity multimodal storytelling application that empowers kids to bring their hand-drawn doodles to life as animated interactive videos. 

This repository implements a production-ready, highly resilient pipeline that combines digital drawing canvases, multimodal Gemini intelligence (from the `@google/genai` SDK), background segmentation, and the **deAPI Video Animation** service (`https://api.deapi.ai/api/v2/videos/animations`) with absolute efficiency.

---

## 🏗️ System Architecture & Data Flow

```
+------------------+                   +------------------+                   +-----------------------+
|  React Client    | --(1) Upload PNG--> |  Express Server  | --(2) Multimodal-> |   Gemini AI Engine    |
| (Drawing Canvas) |                     |   (server.ts)    | <--(3) Classify &  | (gemini-2.5-flash etc)|
+------------------+                   +------------------+      Motion Prompt---+-----------------------+
        ^                                      |
        |                                 (4) Send multipart/form-data
        |                                      |
        |                                      v
+------------------+                   +------------------+
| Webhook Listener | <---(6) Callback- |    deAPI Video   |
|   /api/v1/...    |    (MP4 URL video) |    Gen Server    |
+------------------+                   +------------------+
```

1. **Ink Capture & Rasterizer**: In-browser HTML5 canvas capturing child doodles, converting inline SVGs to transparent high-contrast `.png` streams to prevent API parsing crashes.
2. **Express Multiplexer (`server.ts`)**: Manages the local JSON-based storage engine (`db.json` via `/src/server/db.ts`), static file streams, and initiates the pipeline.
3. **Gemini Vision Classification**: Parses the raw image, identifies the category of creature (doodle matching), generates structured narrative metadata, and builds a targeted kinetic motion prompt.
4. **deAPI Dispatch (Ltxv Model)**: Sends the processed doodle binary stream as a multipart form file directly into the deAPI animation server, caching the generated `request_id` onto the database record.
5. **Async Event Callback Listener**: An open public webhook pipeline accepts finished render callbacks from deAPI, matching incoming `request_ids` or `track_ids` instantly, and commits the finalized, playable MP4 URL to the client.

## ⚡ Technical Accomplishments & Pipeline Stabilizations

### 1. Canvas SVG Rasterizer & PNG Extractor
* **Why it was built**: RAW SVG vector drawings generated by client-side browser boards crashed standard background segmentation files and the Gemini multimodal payload interpreter.
* **Solution**: Developed a memory-buffer rendering loop. It intercepts inline vector-curves, draws them into offscreen HTML5 `CanvasRenderingContext2D` contexts with precise transparent parameters, and outputs high-fidelity rasterized `image/png` streams.

### 2. Multi-Model Gemini Failover & Exponential Backoff
* **Why it was built**: High-demand educational lab traffic caused frequent rate limit spikes and structural capacity errors.
* **Solution**: Developed a dynamic retry loop inside `/src/server/gemini.ts` equipped with localized exponential backoff and a robust failover chain:
  1. `gemini-2.5-flash` (Primary narrative generator)
  2. `gemini-2.0-flash` (First active replica failover)
  3. `gemini-1.5-flash` (High-capacity baseline backup)

### 3. deAPI Video Animation Connector & Cost Presets
* **Endpoint**: `POST https://api.deapi.ai/api/v2/videos/animations`
* **Form Structure**: Pure `multipart/form-data` with raw PNG buffers bound as independent asset-streams (`first_frame_image.png`).
* **Optimized Free-Tier Presets**: Strictly calibrated request structures configured inside `/server.ts` and `/backend/src/services/aiService.ts` to satisfy deAPI strict model parameters while preserving development credits:
  * **Model**: `"Ltxv_13B_0_9_8_Distilled_FP8"` (Distilled, low-latency character dynamics).
  * **Width & Height**: `512` x `512` (Bypasses premium pricing tier of 1024px assets).
  * **Steps**: `1` (Optimized distilled model setting for maximum performance and validation bypass).
  * **Frames**: `30` (Meets the strict deAPI validation rule where frames must be at least 30, avoiding 422 HTTP validation faults).
  * **FPS**: `30` (Matches frame rate with the 30-frame output sequence).
  * **Guidance Scale**: `7.5` / **Seed**: `42`.
  * **Negative Prompt**: `"blur, low quality, static, deformed, extra limbs"`.

## 💾 Core Databases & Schemas (`/src/server/db.ts`)

Data is persisted locally in structural JSON segments mapped inside `/data/db.json` and served via unified service bindings. The datastore enforces tight interface integrity:

### Drawing Record (`Drawing` interface)
```typescript
export interface Drawing {
  _id: string;              // Unique identifier (UUID or custom timestamped hash)
  filename: string;         // Local file name stored in /data/uploads/
  processedUrl: string;     // Transparent cutout asset URL path
  classification?: string;  // Gemini parsed doodle identifier
  motionProfile?: string;   // Action behaviors: ["swim", "fly", "launch", "bounce"]
  createdAt: string;        // UTC epoch
}
```

### Story / Animation Record (`Story` interface)
```typescript
export interface Story {
  _id: string;              // Correlated unique identifier
  drawingId: string;        // Reference key for the source Drawing record
  title: string;            // Gemini contextual narration title
  chapters: {               // Multi-part educational storyboard segments
    text: string;
    narratorSpeech?: string;
  }[];
  motionPrompt?: string;    // Custom motion prompt generated specifically for the character
  videoUrl?: string;        // Playable MP4 result returned from deAPI animation service
  deapiRequestId?: string;  // Asynchronous tracking token retrieved on initial dispatch
  reviewStatus?: string;    // Status node: "pending" | "approved" | "rejected"
  createdAt: string;        // UTC timestamp
}
```

## 📡 Webhook Event Handler & Router (`/api/v1/webhooks/deapi`)

Since deAPI operations execute asynchronously, the application exposes a highly comprehensive listener capable of parsing multiple payload structures:

### Event Capture & Match Routing:
```typescript
app.post("/api/v1/webhooks/deapi", express.raw({ type: "application/json" }), async (req, res) => {
  const payload = JSON.parse(rawBodyString);
  
  // 1. Double Correlation Pattern (Track ID or Request ID match)
  let storyId = payload.track_id || payload.data?.track_id;
  let story = storyId ? await dbService.findStoryById(storyId) : null;
  
  if (!story) {
    const requestId = payload.request_id || payload.id || payload.data?.request_id || payload.data?.id;
    if (requestId) {
      const stories = await dbService.findStories();
      story = stories.find(s => s.deapiRequestId === requestId) || null;
      if (story) storyId = story._id;
    }
  }
  
  // 2. Parse State Transitions
  const isCompleted = payload.event === "job.completed" || payload.event === "video.completed" || payload.status === "completed";
  const isFailed = payload.event === "job.failed" || payload.status === "failed";
  
  if (isCompleted) {
    const resultUrl = payload.data?.result_url || payload.data?.video_url || payload.result_url || payload.url;
    await dbService.updateStory(storyId, { videoUrl: resultUrl, reviewStatus: "approved" });
  }
});
```
